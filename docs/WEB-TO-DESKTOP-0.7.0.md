# Circle Windows 0.7.0 — перенос возможностей веб-версии

База: Circle Site 5.2.3 + Mobile API 0.6.0; Windows 0.6.1. Это **нативный Flutter-клиент**, WebView не используется. При обновлении сайта данные и таблицы не удаляются.

## Новые возможности и маршруты

| Веб-функция | Нативная реализация | API |
|---|---|---|
| Управление паролем, логином, подключёнными устройствами и веб-сеансами | «Безопасность» | `desktop-security`, `desktop-password-change`, `desktop-username-change`, `desktop-device-revoke` |
| TOTP: включение, отключение, резервные коды | «Безопасность» | `desktop-totp-start`, `desktop-totp-enable`, `desktop-totp-disable` |
| Создание, выход из сообщества | «Сообщества» | `desktop-community-create`, `desktop-community-leave` |
| Настройки сообщества, аватар и обложка | Панель сообщества | `desktop-community-panel`, `desktop-community-appearance`, `desktop-community-image-upload` |
| Текстовые каналы: создание, переименование, удаление | Панель сообщества | `desktop-channel-create`, `desktop-channel-rename`, `desktop-channel-delete` |
| Голосовые каналы: создание, закрытие и открытие | Панель сообщества | `desktop-voice-channel-create`, `desktop-voice-channel-lock` |
| Роли, наборы разрешений, назначение, блокировка | Панель сообщества | `desktop-role-create`, `desktop-role-permissions`, `desktop-role-assign`, `desktop-member-ban` |
| Приглашения: срок действия/отзыв | Панель сообщества | `desktop-invite-create`, `desktop-invite-revoke` |
| Антиспам: ссылки и замедление сообщений | Панель сообщества | `desktop-automod` |
| ЛС: редактирование, удаление, архив | Мессенджер | `desktop-dm-edit`, `desktop-dm-delete`, `desktop-dm-archive`, `desktop-dm-archives` |
| Каналы: редактирование, удаление, закрепление сообщений, жалобы | Текстовые каналы | `desktop-channel-edit`, `desktop-channel-message-delete`, `desktop-channel-pin`, `desktop-channel-report` |
| Групповые встречи с друзьями | «Групповые встречи» + существующий LiveKit | `desktop-meetings`, `desktop-meeting-create`, `desktop-meeting-token` |
| Trust & Safety: правила, TXT/DOCX, дела модерации | «Trust & Safety» для администраторов | `desktop-trust-panel`, `desktop-trust-rule-add`, `desktop-trust-rule-toggle`, `desktop-trust-import`, `desktop-trust-review` |

Существующие сценарии 0.6.1 не удалены: лента, публикации, реакции и ответы, репосты, истории, профиль, дружба, мессенджер с аудио/файлами, сообщества, звонки, уведомления, базовая админсводка, подписанные обновления.

## Изменения интерфейса

- Цветовая основа сайта — #101113 / #191B1F / #C6A15B, мягкая золотая рамка и локальная подсветка только у активных элементов.
- Сворачиваемая навигация, прокручиваемый sidebar, компактные вторичные экраны и кнопки, которые переносятся при узком окне.
- Изолированная от перерисовки навигация и RepaintBoundary для экранов; кэш изображений ограничен количеством и памятью. Тяжёлые медиа не загружаются пачкой.

## Ограничения и тестирование

Код API и UI подготовлен, но **не подтверждён запуском на реальной Windows/с MySQL**. До заявления о полном паритете необходимы тесты PHP+MySQL, Flutter analyze/test и ручная проверка: TOTP, LiveKit, загрузки на конкретном хостинге, обновления с 0.6.1, роли и права нескольких пользователей, медиа, админские операции.

Пока **не заявляем полной реализации** таких возможностей веб-версии, как расширенные кинозалы, полная административная консоль, автоматический анализ видеосодержимого (требуется отдельный сервис распознавания), OS push-уведомления, полный комплекс наград и параметров приватности. Функции, отключённые на веб-сайте, не включаются через API в обход админских флагов.

Выполнять серверный патч нужно **до** обновления клиента, иначе новые маршруты возвращают NOT_FOUND.
