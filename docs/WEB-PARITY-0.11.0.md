# Circle Web 5.2.3 → Windows 0.11.0: карта функционального соответствия

Эта таблица — **аудит исходников**, а не акт успешного сквозного тестирования на Windows. Отмечайте `Проверено` только после тестов с актуальным сервером и двумя аккаунтами.

| Модуль сайта | Windows-код | Реальный end-to-end статус |
|---|---|---|
| Авторизация, 2FA, восстановление сессии | есть в базе 0.10 | не проверено в этом релизе |
| Лента, посты, реакции, истории, комментарии, ответы, репосты | нативные экраны в базе 0.10 | не проверено в этом релизе |
| Профиль, обложка, друзья и заявки | нативные экраны в базе 0.10 | не проверено в этом релизе |
| Личные переписки, вложения, реакции, голосовые | нативные экраны в базе 0.10 | звук/Windows API проверить |
| Сообщества, приглашения, роли, каналы | часть управления в базе 0.10 | проверить права и группы |
| Видеозвонки и голосовые встречи | LiveKit-код в базе 0.10 | проверить камеру/микрофон/допуски |
| Системный Windows toast + звук | **добавлено в 0.11** | требует ручного теста на Windows |
| Перенаправление по нажатию (DM/публикация/друзья/сообщество/канал/встреча) | **добавлено в 0.11** | требует теста реальных событий |
| Центр уведомлений, фильтрация, настройки, прочтение | **переработано в 0.11** | требует теста API |
| Админская модерация жалоб, история, Trust | частично реализовано в базе 0.10 | не проверено в этом релизе |
| Кинозалы (плеер, синхронизация, медленный клиент) | только часть навигации/комнат | **неполный перенос** |
| Расширенные админские блокировки, разбор фото/видео | частично в вебе | **неполный перенос** |
| Уведомления, когда Circle полностью завершён | отсутствует фоновая служба | **не реализовано** |
| Подписанные обновления без установщика | механизм из 0.10 сохранён | Windows сквозной тест обязателен |

## Инженерные приоритеты после 0.11

1. Проверить 0.11 на Windows 10/11: toast + звук, клики в разные типы событий, смена аккаунта, сворачивание и DND.
2. Провести сквозные тесты LiveKit, голосовых сообщений и мессенджера с двумя пользователями.
3. Реализовать полноценные кинозалы со state-синхронизацией и восстановлением после переподключения.
4. Довести администрирование и модерацию в Windows до уровня сайта; добавить недостающие маршруты с проверкой прав.
5. Ввести измеряемые показатели скорости: время первого экрана, p95 загрузки переписок, FPS при прокрутке, потребление ОЗУ.
6. После подтверждения Windows-обновлений — безопасная миграция с публичного GitHub Releases на отдельный публичный канал обновлений.

Ни одна строка этого документа не означает, что функция считается исправленной без тестирования на реальном сервере.
