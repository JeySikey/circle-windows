# Circle Windows 0.10.0 — кандидат обновления интерфейса

Дата: 12 ноября 2026 года. Основа — исходники Windows 0.9.0, переданные пользователем без последующих изменений. Последний предоставленный Windows CI подтверждает 27 успешных Flutter-тестов и проверки updater; пользователь подтвердил нормальную работу обновлений на своём ПК.

## Изменения

- Боковое меню остаётся доступным во вторичных разделах. Профиль закреплён внизу, список разделов прокручивается отдельно. Повторный выбор активного пункта меню не создаёт ещё один такой же экран.
- Основные разделы и их состояние сохраняются при переходе во вторичный раздел и возвращении. Неназванные вложенные страницы сохраняют выделение родительского раздела.
- Ctrl+K открывает быстрый переход, Ctrl+1–4 — основные вкладки, Alt+← возвращает на предыдущий экран внутри рабочей области. Навигация учитывает запрет выхода с экрана: она не снимает защищённый маршрут принудительно.
- Шапка учитывает ширину рабочей области и масштаб текста. Дополнительные действия переходят в меню, заголовки не вытесняют кнопки. Анимация сворачивания учитывает системное уменьшение движения.
- Пункты меню и кнопки действий показывают клавиатурный фокус в светлой и тёмной темах, сообщают доступное название, выбранное и отключённое состояние.
- Мессенджер выбирает одну или две панели по доступной ширине после бокового меню. При сужении выбранный чат остаётся открыт; кнопка возвращает к списку диалогов. При изменении ширины сохраняются состояние диалога и черновик.
- Черновики разных собеседников изолированы. Запоздавший опрос старого чата не подменяет текущий. При смене собеседника несохранённый черновик очищается; постоянное хранение черновиков не добавлялось.
- Шапка чата и поле ввода адаптируются к узкой области и увеличенному тексту. Голосовые/видеозвонки, архив и обновление сообщений доступны через меню.
- Запись с микрофона инициализируется при её использовании. Если запрос начала звонка завершился после ухода из диалога, созданное приглашение завершается на сервере.

## Проверки

Проверки выполняются на Flutter 3.47.9 / Dart 3.13.7 — той же версии Flutter, которая указана в предоставленном логе CI. Workflow закреплён на этой версии SDK; pubspec.lock фиксирует разрешённые зависимости.

Локально успешно прошли все 41 Flutter-тест и analyze (без ошибок/warnings; 7 информационных замечаний об устаревших API). Реальные логи локальных analyze, Flutter-тестов и проверок пакета находятся в `docs/validation/`. Widget-тесты используют фиктивные ответы API и не обращаются к acircle.ru. Проверены сохранение состояния, навигация, клавиатура, обе темы, узкая область, масштаб текста, запоздавшие ответы и завершение позднего звонка.

Превью получены из реального CircleApp на фиктивных данных через Flutter test renderer в Linux; использован DejaVu Sans вместо Windows Segoe UI. Они показывают компоновку и не заменяют Windows smoke-test.

Локальная среда Linux не подтверждает сборку EXE, Windows DPI, реальный микрофон/камеру, LiveKit, установку и обновление 0.9.0 → 0.10.0. Это нужно проверить на Windows. Измерения FPS/CPU/RAM до и после не проводились; количественный прирост производительности не заявляется.

## Как применить

1. Создайте ветку от текущего Windows main, например `ui-0.10.0`.
2. Загрузите содержимое патча с сохранением путей, включая `.github`. Список — `PATCH-FILES-0.10.0.txt`. Удалений нет. Остальные файлы репозитория сохраните.
3. Запустите Actions → Circle Windows build → Run workflow для этой ветки. Проверки, установщик и артефакты собираются; публикация Release для рабочей ветки пропускается.
4. Проверьте на Windows: вход, четыре вкладки, дополнительные разделы и возврат, Ctrl+K/Ctrl+1–4/Alt+←, сворачивание меню, окно 760×550 и обычное окно, масштаб текста 100/150/200%, обе темы, два диалога, вложения и микрофон, звонок и его завершение.
5. После успешной проверки перенесите изменения в main/master. Существующий механизм выпуска создаст подписанный релиз v0.10.0. Используйте прежний `CIRCLE_UPDATE_PRIVATE_KEY_PEM`.
6. Проверьте обновление установленного 0.9.0 до 0.10.0, сохранение авторизации и пользовательских данных. Исполняемые файлы должны быть из этого CI, а не из старого релиза.

Эта итерация не требует FTP-патча, изменения PHP/MySQL или миграций сайта. Android в неё не входит.
