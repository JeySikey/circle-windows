# Circle Windows 0.4.1 — план ручных испытаний

## A. Сборка/установка
- [ ] GitHub Actions: Resolve dependencies, Analyze, Unit tests, Release build, Inno Setup зелёные
- [ ] Артефакт Setup содержит EXE и устанавливается на Windows 10/11 x64
- [ ] Значок Circle виден в меню Пуск, на панели задач и установщике
- [ ] Обновление поверх 0.3.2 проходит без потери локальной авторизации и данных сервера
- [ ] Выход из приложения освобождает камеру, микрофон, видео и аудиоплееры

## B. Авторизация/UI
- [ ] Вход по username/email, неверные credentials, 2FA, выход, повторный запуск
- [ ] Сайдбар (4 главных пункта), сворачивание, переключение темы, окно 760px/1366px/4K
- [ ] Прокрутки, нет горизонтального overflow и закрытых кнопок
- [ ] Аватары, обложки и текст не раскрываются без прав; отсутствие сети даёт понятную ошибку

## C. Контент
- [ ] Публикации текст, фото JPG/PNG/WebP, видео MP4/WebM; отображение, лайк и отмена
- [ ] Комментарии/ответы и исправный parent_comment_id
- [ ] Истории фото/видео, подпись <=180 символов и ограничения доступа
- [ ] Профиль: имя, статус, bio, аватар, награды, просмотры чужих профилей

## D. Переписка
- [ ] Два аккаунта: текст, ответ на сообщение, реакции, файл, фото, видео
- [ ] Запись и отправка голоса (WAV), воспроизведение, пауза, seek, 2+ записи подряд
- [ ] Отказ в доступе к микрофону, файл >30 MB, закрытие окна во время воспроизведения

## E. Сообщества и администрирование
- [ ] Вступление только по валидной ссылке-приглашению и ограничение повторного вступления
- [ ] Каналы, реакции, новость, медленные каналы, ограничение прав
- [ ] Уведомления/настройки, админская сводка для владельца и запрет для обычного пользователя

## F. Звонки LiveKit (критические)
- [ ] На двух разных устройствах вызов, входящий диалог, принятие, отказ, отмена, завершение
- [ ] Звук в обе стороны, переключение микрофона, камера/видео в обе стороны
- [ ] Разрыв сети, переподключение, отсутствие живого звонка после отмены
- [ ] Голосовой канал сообщества с 2+ участниками и выключение камеры/микрофона
- [ ] Отсутствие URL/токена LiveKit в пользовательских логах

## G. Обновления и безопасность
- [ ] Без конфигурации канал честно сообщает о настройке
- [ ] Подписанный релиз обнаруживается; подменённый манифест/EXE отвергается
- [ ] HTTPS->HTTP redirect не принимается; валидный redirect GitHub Releases работает
- [ ] Обновление устанавливается только после согласия и закрытия приложения
- [ ] Приватный ключ не присутствует в репозитории или артефактах

Записывать фактические результаты: «пройдено», «дефект», «не проверено», журнал GitHub/Windows и шаг воспроизведения. Ни один пункт не считать пройденным лишь по факту наличия кода.
