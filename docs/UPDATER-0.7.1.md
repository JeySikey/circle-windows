# Circle Windows 0.7.1 — восстановление автообновлений

Это **патч исходников GitHub**, не ZIP для передачи прямо приложению. В его состав входят только новые/изменённые файлы по сравнению с репозиторием 0.7.0.

## Что исправлено

- После загрузки клиент **не закрывается**, пока отдельный PowerShell-обновлятор не проверит ZIP (повторный SHA-256), распакует его в безопасную временную папку и не пришлёт подтверждение готовности.
- При ошибке подготовки клиент остаётся открыт, и пользователю показывается путь к журналу.
- После закрытия старого клиента обновлятор перемещает прежнюю папку в резервную копию и ставит новую, проверяет запуск и делает откат при неудаче.
- Сохраняются файлы Inno Setup `unins000.*`, чтобы Windows могла удалять установленную программу после обновления.
- Ошибка замены сохраняется в `%LOCALAPPDATA%\Circle\updates\last_result.json` и показывается пользователю после повторного запуска.
- На GitHub Actions добавлен реальный тест ZIP-обновления тестовой папки, имитация сбоя после замены с проверкой отката и отказ при подменённом ZIP.

## Публикация

1. Загрузить содержимое PATCH ZIP в **корень** существующего GitHub-репозитория, заменяя одноимённые файлы. Остальные файлы сохраняются.
2. Запустить `Actions → Circle Windows build`. Проверить успешность **Integration-test in-place updater with real ZIP and rollback guard**.
3. Убедиться, что в `Releases` есть `v0.7.1` с `update-manifest.json`, ZIP и установщиком. Приватный ключ подписания НЕ менять.
4. Если установленная версия умеет применять обновления, она обнаружит `v0.7.1`. **Если текущий обновлятор уже неисправен, он не может заменить себя удалённо:** может понадобиться один раз скачать и запустить установщик `Circle_Windows_0.7.1_Setup.exe` поверх старой версии. Удалять старую версию и пользовательские данные не требуется.
5. Чтобы доказать работу *нового* механизма, опубликовать тестовую версию `0.7.2` и проверить обновление из установленной `0.7.1` без ручного скачивания и переустановки.

## Диагностика при следующей ошибке

Открыть `%LOCALAPPDATA%\Circle\updates\update.log` через Win+R → вставить путь. Отправить последние 30–50 строк, скрыв личные пути и другую приватную информацию. Также полезен `%LOCALAPPDATA%\Circle\updates\last_result.json`. **Не отправлять приватные ключи GitHub, PAT и токены пользователей.**

## Что проверено

Локально: структура исходников, версия, Python-тесты релиза и подписанного пакета, проверка наличия сценариев CI. **Windows EXE, PowerShell 5.1 и реальная установка/откат будут проверяться в GitHub Actions**. Сквозной тест на компьютере пользователя остаётся обязательным.
