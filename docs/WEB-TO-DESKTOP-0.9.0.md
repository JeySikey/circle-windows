# Circle Windows 0.9.0 — перенос веб-функций и интерфейс

Исходная база: Circle Windows 0.8.1 + Desktop API сайта Circle 5.2.3 версии 0.8.0.

## В этом релизе

- **Жалобы на сообщения**: очередь, перевод в работу, закрытие с основанием и записью предупреждения в журнал, архив с историей действий. Совпадает с моделью `moderation_reports` веб-версии. Сервер разрешает доступ только OWNER/ADMIN.
- **Жалоба на DM**: пользователь вручную отправляет обращение по конкретному чужому сообщению. Сервер проверяет участие в диалоге и авторство, ограничивает 5 жалоб за 24 часа, предотвращает повторные обращения по тому же сообщению.
- **Системы платформы**: администратор видит включённые модули из `platform_features`, меняет их с подтверждением отключения, просматривает журнал действий (`audit_log`).
- **Поиск по разделам**: Ctrl+K; переходы между четырьмя основными вкладками Ctrl+1…Ctrl+4. Поиск локальный, без дополнительных HTTP-запросов.
- **Мессенджер**: отдельная страница диалога при ширине окна менее 980 px. На широких окнах сохраняется двухпанельный режим.
- **Дизайн**: мягкое золото при наведении на сообщения и пункты палитры, плавные переходы без постоянно работающих контроллеров анимации, компактное контекстное меню в верхней панели.
- **Производительность**: запросы изображений используют реальный LRU, невидимые разделы сохраняются без повторной загрузки, фоновые звонки не опрашиваются, когда приложение скрыто.

## Сервер

Для новых методов достаточно заменить `api/desktop_ext.php` из отдельного FTP-патча. `api/mobile.php` версии Desktop API 0.8.0 уже подключает `desktop_ext.php`, SQL-миграций **нет**. Сохраняются таблицы, аккаунты, файлы и авторизация. Делайте резервную копию до замены.

## Проверка безопасности

- Для любого чтения администраторских данных `desktop_admin($actor)` вызывается до запроса SQL.
- Смена состояния жалобы происходит в транзакции, с `SELECT … FOR UPDATE`, запретом повторного решения и аудиторской записью.
- Обращение на DM доступно только участнику 1:1-диалога, не позволяя читать чужую переписку.
- Включение/отключение модуля проверяется через параметризованный SQL; клиент не определяет права.

## Не заявлено как завершённое

Полноценные кинозалы со сторонними встроенными видеоплеерами, отдельные Windows push-уведомления, полнофункциональное администрирование всех подсистем, полное соответствие всех групповых режимов LiveKit веб-версии и автоматический анализ видео. Требуются отдельные API/нативные реализации и сквозные испытания.

## Тесты

Включены новые Flutter widget-тесты для командной палитры, модерации и модулей; статические Python проверки прав, синтаксический контроль PHP. `flutter analyze`, `flutter test` и Windows-интеграционный тест выполняются в GitHub Actions — локально Flutter SDK не установлен. Результат GitHub нужно проверить перед публикацией релиза.
