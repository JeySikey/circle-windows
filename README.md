# Circle Windows Native 0.3.1 (исходный GitHub-проект)

**Твой круг. Твои люди.**

Это **новая ветка нативного Flutter-клиента** для Windows 10/11, не WebView и не обёртка над сайтом. Приложение использует существующий PHP API сайта Circle 5.2.3 (`/api/mobile.php`). Сервер и база данных не включены в этот репозиторий и не изменяются.

## Получение установщика через GitHub

1. На GitHub создайте пустой **private** или public репозиторий, например `circle-windows`.
2. **Распакуйте ZIP** и загрузите *содержимое каталога* в корень репозитория. ZIP как единственный файл загружать нельзя: GitHub Actions не распаковывает его автоматически.
3. В разделе **Actions** разрешите запуск workflow `Circle Windows build` (если GitHub запросит подтверждение). Workflow запустится при загрузке в `main`, либо запустите его вручную через **Run workflow**.
4. В успешном запуске откройте **Artifacts → Circle-Windows-Setup**. Скачайте ZIP с `Circle_Windows_0.3.1_Setup.exe` внутри. Дополнительно доступен портативный комплект `Circle-Windows-Portable`.
5. Установите приложение на Windows 10/11 x64. В нём указан сервер по умолчанию `https://acircle.ru` — замените адрес на ваш, если нужен другой.

Сборка выполняется на облачном `windows-latest` runner, локальная установка Flutter не обязательна. GitHub **не создаёт установщик из ZIP автоматически**: ему нужен исходный репозиторий с файлом `.github/workflows/windows.yml`.

## Сборка на своём Windows ПК

Нужны Flutter stable, Visual Studio 2022 с Desktop development with C++, Windows SDK, Inno Setup 6. Запустите из каталога проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-installer.ps1
```

### Функции, которые **пока не реализованы как полноценные нативные**

- LiveKit аудио- и видеозвонки, демонстрация экрана, входящий звонок; пока только история вызовов.
- Запись/воспроизведение голосовых сообщений, полноценные видеовложения и видеоистории.
- Полная административная панель, модерация, редактор изображений, управление ролями/настройками сообществ, групповые звонки.
- Поиск и отправка заявок друзьям (серверный Mobile API 5.2.3 не содержит соответствующего полного набора маршрутов).
- Фоновый Windows push, системный трей, автозапуск, офлайн-кеш.
- Автоматическая публикация **подписанных** обновлений в GitHub Releases: реализован клиент проверки, но релизный канал необходимо настроить.

**Не считать этот пакет функциональным эквивалентом веб-версии:** он является тестовой нативной веткой. Приложение не было скомпилировано здесь: Flutter и Windows toolchain недоступны. GitHub Actions выполнит реальный `flutter analyze`, `flutter test` и сборку и остановится на ошибке. Пользовательские данные веб-проекта не мигрируют и не переписываются.

## Настройка обновлений в интерфейсе

При сборке задайте GitHub Actions Variables `CIRCLE_UPDATE_URL` (HTTPS URL подписанного `update-manifest.json`) и `CIRCLE_UPDATE_PUBLIC_KEY` (публичный Ed25519 ключ в base64). Без них раздел «Обновления» сообщает, что релизный канал не настроен. Никогда не добавляйте приватный ключ подписи в репозиторий.

Скрипт `tool/sign_release.py` создаёт ключи и подписанный манифест после появления установщика. Требуется Python с `cryptography`:

```powershell
python -m pip install cryptography
python tool/sign_release.py --generate-key --private-key release-private-key.pem
python tool/sign_release.py --private-key release-private-key.pem --package dist/Circle_Windows_0.3.1_Setup.exe --version 0.3.1 --url https://example.com/Circle_Windows_0.3.1_Setup.exe --output update-manifest.json
```

Храните приватный ключ вне GitHub репозитория. Запуск нового установщика в текущей реализации требует согласия пользователя; до следующего релиза нужно проверить поведение установщика при закрытии приложения.

## Порядок тестирования

1. GitHub Actions зелёный (`analyze`, тесты, компиляция, Inno Setup).
2. Запуск EXE на чистой Windows 10 и Windows 11.
3. Вход с обычным аккаунтом и с 2FA.
4. Проверка реальных постов, комментариев с ответами и публикации медиа.
5. Диалоги, реакции, вложения, истории, каналы, уведомления.
6. Анализ серверных ошибок 403/422 и ограничений прав, проверка модерации и недоступных функций.
7. Проверка канала обновлений отдельно с подписанным релизом.

## Безопасность

- Принудительный HTTPS, bearer-токен хранится в защищённом хранилище ОС.
- Токен не добавляется к URL картинок и файлов, а пересылается в заголовке Authorization.
- Скачанные обновления проверяются Ed25519 и SHA-256.
- Архив не содержит секретов LiveKit, паролей пользователей или базы данных.

- Устранены замечания `curly_braces_in_flow_control_structures` и `use_build_context_synchronously`, показанные в журнале GitHub Actions.
- Версия синхронизирована в приложении, `pubspec.yaml`, Inno Setup и Windows workflow.

**Ограничение проверки:** этот архив проходит проверку целостности ZIP и статическую проверку согласованности файлов. Фактический `flutter analyze`, `flutter test` и сборку Windows выполнит GitHub Actions; в текущем окружении Flutter SDK отсутствует.
