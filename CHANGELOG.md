# История изменений Circle Windows

## 0.4.1 — исправления GitHub Static analysis (тестовый кандидат)
- Устранён конфликт `CircleAvatar` из Flutter Material с пользовательским виджетом, который теперь называется `CircleUserAvatar`.
- Исправлено повторное использование имени `_` в трёх аргументах `Image.errorBuilder`.
- Параметры комнаты LiveKit перенесены в конструктор `Room`, как предписывает обновлённый SDK.
- Выровнены версии приложения, сценария Inno Setup, GitHub Actions и документации.
- Добавлен тест виджета аватара и дополнительная проверка исходного пакета перед сборкой.
- Компиляция и `flutter analyze` в этой среде недоступны; исправления требуют подтверждения новой сборкой GitHub.

## 0.4.0 — переработка нативного интерфейса (тестовый кандидат)
- Воссоздан дизайн-токен Circle 5.2.3, разработаны собственные экраны ленты, профиля, диалогов, друзей, сообществ, уведомлений.
- Из исходного SVG сайта создан знак для приложения и иконка установщика.
- Добавлены изображения и видео через локальный плеер, WAV запись и воспроизведение голосовых сообщений, включён ползунок позиционирования.
- Добавлен нативный клиент LiveKit для личных аудио/видеозвонков, входящих приглашений и голосовых каналов.
- Добавлены заявки по ссылкам-приглашениям, статусы наград, настройки уведомлений, кинозалы, административная сводка.
- Улучшена безопасность обновлений: подписанный манифест Ed25519, проверка SHA-256, допустимые HTTPS-редиректы, скрипт публикации тегированных GitHub Releases.
- Разработаны тестовый план и новая инструкция GitHub.
- Остались непроверенными Windows-компиляция и реальное поведение LiveKit/медиа; не помечать релиз стабильным до испытаний.
