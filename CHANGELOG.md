# Circle Windows Native — история исправлений

## 0.3.1 — корректировка первой сборки GitHub Actions

- Исправлен несуществующий метод `Sha256.hashStream` в загрузчике обновлений.
- Введено потоковое SHA-256 хеширование файлов через `package:crypto`.
- Добавлен регрессионный тест на хеширование бинарного файла.
- Добавлены проверки `context.mounted` перед использованием контекста после `await`.
- Исправлены фигурные скобки при освобождении контроллеров экрана входа.
- Обновлены версии клиента и установщика.

Это исправление ошибок статического анализа, а не завершение недостающих функций клиента.
